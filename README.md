# kamila_computer_programming
Project Update & Metodology Shift
Originally, I planned to to write a Python script for ArcGIS Pro to automatically detect and vectorize water bodies. However, during preparation, I realized that ArcGIS includes built-in tools (such as Change Detection for time changes between rasters), and it also requires a licensed Windows environment. Therefore, I decided to transition the project to QGIS, which is open-source (free), runs natively on macOS, and does not offer a single-click automated tool for this specific sequence of steps (brightness thresholding and direct vectorization to polygons). Writing a custom PyQGIS script thus brings real practical value. 
Status 11.11.2026: I created a GitHub account, set up the repository, and invited my professor (Computer programming) as a collaborator to track code updates. I successfully and opened the integrated Python console within QGIS. Since I have no prior experience with PyQGIS, I am currently familiarzing myself with the QGIS object model and the processing framework. I already tried generating the polygons, but the simple brightness thresholding gave me some incorrect results, instead of just the river, it selected random noisy points and shadows around it, which I need to fix next.
